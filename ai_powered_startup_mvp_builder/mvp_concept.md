# MVP Concept - AI Feedback Hub

## Problem Statement
Small product teams and startup founders struggle to collect, summarize, and extract actionable insight from unstructured user feedback efficiently.

## Target Users
- Startup founders
- Product managers
- UX researchers
- Customer success leads

## Core Features
- Interactive feedback submission form with text and rating fields
- Automated AI-powered sentiment analysis and feedback summarization
- Centralized feedback dashboard with real-time search and filter tools
- One-click CSV export functionality for recorded user responses

## Constraints
- Single-tenant setup without user authentication
- Storage limit capped at 100 feedback submissions
- Single-page application architecture
