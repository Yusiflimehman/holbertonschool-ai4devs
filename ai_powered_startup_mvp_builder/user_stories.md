# User Stories

## User Story 1
As a user, I want to submit feedback through a form so that I can share my thoughts quickly.

## User Story 2
As a user, I want to view a confirmation message upon form submission so that I know my feedback was received.

## User Story 3
As an admin, I want to view a list of all submitted feedback entries so that I can review user input.

## User Story 4
As an admin, I want to search feedback by keywords so that I can find relevant topics quickly.

## User Story 5
As an admin, I want to filter feedback entries by rating so that I can prioritize lower scores.

## User Story 6
As an admin, I want to view AI-generated summaries of feedback so that I can save time reading long responses.

## User Story 7
As an admin, I want to export feedback as a CSV file so that I can analyze data offline.

## User Story 8
As an admin, I want to delete specific feedback entries so that I can clean up invalid submissions.

## User Story 9
As a user, I want a mobile-friendly interface so that I can easily submit feedback on smartphone screens.
